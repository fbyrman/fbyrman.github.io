Training or fine-tuning a neural network means taking thousands of small gradient steps, each of which needs a pass over the data. This paper asks whether another network can learn to take all of those steps at once: read the weights of a trained network, and return better weights in a single forward pass. 1 Optimisation in one step

Ordinary optimisation solves every problem from scratch. Gradient descent knows nothing about the thousand similar problems it solved before; it starts at $\theta$ and walks downhill until the loss stops improving. Amortised optimisation spends that effort once, up front: it trains a model on a whole family of related problems, so that afterwards it can map a new problem straight to its solution. The cost of optimisation is amortised over the family.

In our setting a problem is a trained network, described by its architecture $G$ and weights $\theta$, together with a cost $C$ such as the classification loss on a dataset $D$. The amortised optimiser is itself a network $\hat f_\phi$ with parameters $\phi$, a metanetwork, whose input and output are both weights:

\[ \hat f_\phi(G, \theta) \;\approx\; f^*(G,\theta) \in \operatorname*{arg\,min}_{\theta' \in \Theta} \; C(\theta' \mid \theta, G, D) \] (1)

Figure 1 shows the idea on a two-dimensional loss landscape. Gradient descent (gold) needs dozens of steps, each one a gradient evaluation. The metanetwork (blue) has seen many landscapes like this one during training, and jumps in a single forward pass. Drag the starting point, or pick another problem from the family below the plot.

Earlier work on learning to optimise trains networks to act as optimisers, but they remain iterative: they still take many steps and evaluate the objective at each one. Work on weight prediction generates parameters from the architecture alone, $G \to \Theta$, which is fast but cannot start from weights that already exist. We study the remaining case, $G \times \Theta \to \Theta$: take existing weights and return improved ones in one step, for example to fine-tune a network or to make it sparse.

2 Weight space is full of symmetries

A metanetwork reads weights, and weights are a redundant description of a network. Many different weight settings compute exactly the same function. Physicists call such a redundancy a gauge symmetry: a transformation of the internal description that leaves everything observable unchanged.

Two symmetries matter here. The hidden neurons of a layer can be put in any order, as long as their incoming and outgoing weights move with them: a permutation. And for many activations, a neuron's incoming weights and bias can be multiplied by a factor $q$, as long as its outgoing weights are divided by the same factor: a scaling. With a permutation matrix $P_\ell$ and a diagonal scaling matrix $Q_\ell$ for each layer $\ell$, the transformed weights are

\[ W_\ell' = P_\ell Q_\ell \, W_\ell \, Q_{\ell-1}^{-1} P_{\ell-1}^{-1}, \qquad b_\ell' = P_\ell Q_\ell \, b_\ell \] (2)

which leaves the network's output unchanged, provided the activation commutes with the scaling: $\sigma(Q z) = Q\,\sigma(z)$. For ReLU this holds for any positive $q$. For $\tanh$, which is odd but not linear, only $q = \pm 1$ works: a sign flip.

Try it in Figure 2. Drag a hidden neuron up or down to reorder the layer, or select one and scale it. The weights change, but the function on the right does not. Then switch off the compensation in the next layer, or switch to $\tanh$ and scale by something other than $\pm 1$, and watch the function break.

These symmetries are not a curiosity. A layer of $n$ ReLU neurons can be reordered in $n!$ ways and rescaled along $n$ independent directions, so every network is one point on a large set of functionally identical twins. A metanetwork that sees raw weights has to learn, from data, that all of these twins are the same network.

3 Building the symmetries in

The alternative is to build the symmetries into the metanetwork, so that it treats functionally identical inputs identically by construction. For a metanetwork that outputs weights, the right property is equivariance: if the input network is transformed by a symmetry $\psi$, the output should be transformed in the same way,

\[ \hat f_\phi\bigl(\psi(G,\theta)\bigr) = \psi\bigl(\hat f_\phi(G,\theta)\bigr) \] (3)

so that two equivalent networks are mapped to two equivalent networks. We use Scale Equivariant Graph Metanetworks (ScaleGMNs, Kalogeropoulos et al., 2024). A ScaleGMN turns the input network into a graph, with neurons as vertices carrying the biases and connections as edges carrying the weights. A graph neural network is unaffected by the order of its vertices, which handles permutations. For scaling, each step of the message passing first brings the features to a canonical scale, so the computation cannot depend on which member of a scaling family it was given.

Figure 3 shows what goes wrong without this. The network is as small as it can be, one ReLU neuron, $u(x) = v\,\mathrm{ReLU}(w x)$, so its weights $(w, v)$ form a plane. Every point on a hyperbola $wv = c$ computes the same function, the line with slope $c$: the hyperbolas are the orbits of the scaling symmetry, and the loss is constant along each of them. The task is to fit slope 1. Slide the input along its orbit. The equivariant map (blue) canonicalises first, so its output always lands on the same orbit, and the function it returns never changes. The map without canonicalisation (rose), here a single large gradient step, returns a different function depending on which twin it was given.

In the paper, the symmetry-broken model is a ScaleGMN with the canonicalisation step removed. Everything else, including the parameter count and the connectivity, stays the same, which makes it a clean test of what the equivariance itself contributes.

4 Training the metanetwork

The metanetwork is trained on a zoo of networks that were all trained on the same task, here classifying greyscale CIFAR-10 images. For CNNs we use the public Small CNN Zoo; for MLPs no comparable collection existed, so we trained our own Small MLP Zoo. For every network $\theta$ in a batch, the metanetwork proposes new weights $\hat f_\phi(G,\theta)$, and the loss is computed on what the proposed network does:

\[ \mathcal L(\phi;\theta,B) \;=\; \lambda \,\bigl\lVert \hat f_\phi(G,\theta) \bigr\rVert_1 \;+\; \frac{1}{|B|} \sum_{(x,y)\in B} \mathcal L_{\mathrm{CE}}\bigl(u_{G,\hat f_\phi(G,\theta)}(x),\, y\bigr) \] (4)

The second term asks the new network to classify well. The first, an L1 penalty with strength $\lambda$, asks it to be sparse; with $\lambda = 0$ the metanetwork is a pure fine-tuner. The gradient flows through the proposed network back into the metanetwork: we optimise $\phi$, never $\theta$. After training, the metanetwork is applied to networks and data it has never seen.

5 Results

We compare one forward pass of the metanetwork against fine-tuning each test network with SGD for 25 to 150 epochs. On CNNs, the single pass beats 150 epochs of SGD, with and without the L1 penalty. With the penalty it also cuts the L1 norm of the weights by 88%, against 71% for SGD after 150 epochs. On MLPs it beats SGD on the regularised task; on plain cross-entropy it matches about 25 epochs, which we attribute to the smaller MLP zoo limiting generalisation. All of this takes about 0.05 seconds per network on an NVIDIA A100, against minutes for SGD.

Does the equivariance help? On MLPs, yes: in the validation curves of the paper the symmetry-broken model trains less efficiently, and it ends behind ScaleGMN-B on every measure in the table. On CNNs the picture is murkier. The training curves of the two models are largely similar, the broken model is even slightly ahead on plain cross-entropy, and the regularised broken run did not finish because of numerical instabilities. Kalogeropoulos et al. saw the same pattern: their largest gains were on MLPs, and their gains on CNNs were modest. The last section explains why.

6 Why CNNs have less to gain

An equivariant metanetwork is only as useful as the symmetry it exploits, so the question is how much scaling freedom each architecture has. Any layer, convolutional ones included, can be written as a matrix product $x_\ell = \sigma(W_\ell x_{\ell-1} + b_\ell)$. For an MLP, $W_\ell$ is an arbitrary dense matrix. For a convolution it is a sparse, structured doubly-block Toeplitz matrix, in which every kernel weight is repeated along a diagonal, once for every position the kernel visits.

A scaling $Q_\ell W_\ell Q_{\ell-1}^{-1}$ multiplies row $i$ of $W_\ell$ by the factor $q_i$. A dense matrix stays a dense matrix whatever the factors are. But if two rows of a Toeplitz matrix are scaled differently, a kernel weight that appears in both now takes two different values, and the result is no longer a convolution. Figure 5 lets you try this on a 2 × 2 kernel sliding over a 3 × 3 input.

This is the result we prove in the appendix: the set of scalings that preserve a convolutional layer is a strict subset of those that preserve a dense layer. For an MLP layer with $n$ outputs and $m$ inputs, every pair of diagonal matrices $(Q_\ell, Q_{\ell-1})$ is allowed, $n + m$ dimensions of freedom. For a convolution only $Q_\ell = \alpha I$ and $Q_{\ell-1} = \beta I$ survive, and since only the ratio $\alpha / \beta$ affects the weights, that is one dimension per channel. Across a whole network, an MLP has as many scaling directions as it has hidden neurons plus inputs; a CNN has as many as it has channels, usually far fewer. A metanetwork built to exploit these symmetries simply has less to exploit in a CNN.

7 What to take from it

  1. A scale equivariant metanetwork can fine-tune or sparsify networks it has never seen in one forward pass, on several loss landscapes: CNNs and MLPs, tanh and ReLU, with and without an L1 penalty.
  2. The benefit of building in scaling symmetries depends on how much scaling symmetry the input architecture has, and convolutions have provably less than dense layers.
  3. Two things remain open: extending the approach to arbitrary architectures, and making positive, scale-symmetric models train stably.
