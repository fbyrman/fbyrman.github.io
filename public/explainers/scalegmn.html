Symmetry-Aware Fully-Amortized Optimization with Scale Equivariant Graph Metanetworks

B. Kuipers, F. Byrman, D. Uyterlinde, A. García-Castellanos

NeurIPS 2025 UniReps Workshop, Extended Abstract Track

1 Motivation

Neural networks have grown exponentially in scale, and so has the bill for training them. Yet every network still starts life the same way: random weights, followed by thousands of gradient steps until the loss stops falling. Much of that effort goes into rediscovering what earlier training runs on similar problems already found. So it is worth asking whether optimization itself can be learned.

Metanetworks, neural networks that take other neural networks as input, are a natural tool for this. One application is weight prediction: given only the architecture $G \in \mathcal{G}$ of a new network, a metanetwork predicts a full set of weights $\boldsymbol{\theta} \in \Theta$ for it in a single forward pass. It learns a map $\mathcal{G} \to \Theta$ from architecture space to parameter space (Zhang et al., 2020; Knyazev et al., 2021).

Figure 1. Weight prediction. The metanetwork sees only the architecture, a small MLP here, and returns a full set of weights for it. Edge width shows the size of a weight, blue positive and orange negative; the numbers are illustrative.

Predicted weights are rarely the finished product. You will usually still run some gradient descent to reach the accuracy you want, but you start from a better place in the loss landscape.

In practice, though, we rarely start from scratch. More often we already have a trained network and want to improve it: make it more accurate, say, or make it sparse. That raises a natural question: can the same principle work for networks whose weights already contain information? This is what our proof-of-concept paper is about. The metanetwork reads the existing weights $\boldsymbol{\theta}$ alongside the architecture and returns improved weights $\boldsymbol{\theta}'$ in one forward pass: a map $\mathcal{G} \times \Theta \to \Theta$.

Figure 2. Our setting. The metanetwork now reads the weights the network already has and returns improved ones. No gradient step ever touches the network itself. The numbers are illustrative.

2 Weight space symmetries

Take a trained network and swap two of its hidden neurons, together with their weights. The list of weights now looks different, but the network computes exactly the same function. A change to the weights that leaves the function untouched is called a symmetry, and for a model that works on weights, symmetries are knowledge worth building in. If the model already knows which weights describe the same network, it does not have to learn this from data or spend capacity on the redundancy, which makes it more efficient to train. Two symmetries matter here: reordering hidden neurons, and rescaling them.

2.1 Permutations

A hidden layer is a set of neurons, and the order in which we store them is pure bookkeeping. Reorder the hidden neurons, taking their incoming and outgoing weights along, and the network computes exactly the same function. Try it in Figure 3: drag a hidden neuron up or down. The weight matrices a metanetwork would read change, as rows of $W_1$ and columns of $W_2$ swap places, but every input still gives the same output.

Figure 3. Permuting hidden neurons. The network uses ReLU and the weights of Figure 1, without biases. On the right, the weight matrices as stored: $W_1$ has one row per hidden neuron, $W_2$ one column.

2.2 Scaling

For many activations you can also rescale a neuron. Multiply its incoming weights by a factor $q$, divide its outgoing weights by the same factor, and the network computes the same function, provided the activation commutes with the scaling: $\sigma(qz) = q\,\sigma(z)$. For ReLU that holds for every $q > 0$. For $\tanh$, which is odd but not linear, it only holds for $q = \pm 1$: you can flip the sign of a neuron, but not stretch it. Try it in Figure 4: select a hidden neuron and move the slider, then switch to $\tanh$, or stop dividing the outgoing weights, and watch the function break.

Figure 4. Scaling hidden neurons. Click a hidden neuron to select it; the slider sets its factor $q$, which snaps to $\pm 1$. The network is the one of Figure 3.

2.3 Symmetries in a CNN

Convolutional networks have the same two symmetries, with channels in the role of neurons. Reorder the channels of a layer, taking each channel's kernel and its slice of the next layer's kernel along, and nothing changes. Multiply a channel's kernel by $q > 0$ and divide its slice of the next kernel by $q$, and for ReLU nothing changes either. Try both in Figure 5.

Figure 5. A tiny CNN: a $3 \times 3$ input, three channels with $2 \times 2$ kernels and ReLU, and a second layer that maps the three $2 \times 2$ feature maps to one output. Drag a channel to reorder it; click one to select it for scaling.

Notice that you can only scale whole channels. In the MLP every hidden neuron could be scaled on its own. In a CNN, every position of a feature map is a neuron too, but all positions of a channel are computed with the same kernel. A convolutional layer has no separate weights per position, so there is nothing to scale one position with: giving one position its own factor would need a different kernel at that position, and the layer would no longer be a convolution.

So a convolutional layer has one scaling factor per channel, where a dense layer has one per neuron. In the language of physics, its gauge freedom is smaller. We prove this in the paper: the scaling symmetries of a convolutional layer are a strict subset of those of a dense layer with the same inputs and outputs. Across a whole network the gap is large. An MLP has as many scaling directions as it has hidden neurons and inputs; a CNN has as many as it has channels, which is usually far fewer.

3 Method

Our metanetwork is a Scale Equivariant Graph Metanetwork (ScaleGMN, Kalogeropoulos et al., 2024). It reads a trained network and returns new weights for it, and it has the symmetries of Section 2 built in.

3.1 Networks as graphs

The metanetwork reads the input network as a graph: neurons are vertices that carry their biases, and connections are edges that carry their weights (Kofinas et al., 2024). For a CNN, channels are the vertices and kernels sit on the edges. A graph has no built-in order, so reordering the neurons of a layer changes nothing for the metanetwork. Permutation symmetry comes for free.

3.2 Equivariance

For scaling, every step inside the metanetwork first brings its inputs to a canonical form, in which all rescaled copies of a neuron look the same. The result is a metanetwork that is equivariant: permute or rescale the input network, and the output network is permuted or rescaled in exactly the same way. In Figure 6 that means both routes around the square end at the same network. An ordinary metanetwork has no such guarantee. It has to learn the symmetries from data, and only ever approximately.

Figure 6. Equivariance. Going right applies the metanetwork, going down applies the symmetry. Bottom right is reached by applying the symmetry first; edges where it differs from the other route are outlined. Both metanetworks are simple stand-in maps, not trained models: the equivariant one updates each neuron's weights from that neuron alone, the ordinary one adds a fixed correction to every storage position.

3.3 Training

We train on a model zoo: a large collection of small networks, all trained to classify grayscale CIFAR-10 images (Krizhevsky, 2009). For CNNs we use the public Small CNN Zoo (Unterthiner et al., 2021); for MLPs we built our own. For each network in a batch, the metanetwork proposes new weights, and we measure how well the proposed network classifies. Optionally we add a penalty on the size of the weights, which pushes many of them to zero and makes the network sparse. The error flows back through the proposed network into the metanetwork: we train the metanetwork, never the networks in the zoo.

At test time the metanetwork fine-tunes networks, and images, it has never seen, in a single forward pass. As a reference we fine-tune the same test networks with SGD for 25 to 150 epochs. To isolate what scale equivariance contributes, we also train the same metanetwork without its canonicalization step. In the results, our metanetwork is called ScaleGMN-B and this symmetry-broken version GMN-B.

4.1 One forward pass against 150 epochs

On CNNs, a single forward pass of ScaleGMN-B beats 150 epochs of SGD on the objective it was trained for. Without the penalty it lifts the average accuracy of the unseen test networks from 37.9% to 50.3%, where SGD reaches 44.5%. With the penalty it reaches a lower test loss than 150 epochs of SGD (1.901 against 2.070) and cuts the L1 norm of the weights by 88%, against 71% for SGD, though at a lower accuracy (37.4% against 41.6%). It does all this in about 0.05 seconds per network, where SGD takes six to eight minutes.

On MLPs the picture is mixed. With the penalty, the metanetwork matches the test loss of 150 epochs of SGD (1.964 against 1.963) with a far sparser network, 85% against 55%, but at a lower accuracy. Without the penalty it does about as well as 25 epochs of SGD. We attribute this to the smaller MLP zoo, which gives the metanetwork less to generalize from.

SGD would keep improving with more epochs, so it is not a competitor to be beaten forever. It is a reference point: a metanetwork that has never seen these networks, or these test images, gets in one step where an optimizer tuned to each network needs minutes.

4.2 Does the equivariance help?

For MLPs, yes. Without canonicalization, the metanetwork trains less efficiently, and the symmetry-broken GMN-B ends behind ScaleGMN-B on every accuracy, loss and sparsity measure in Table 1.

For CNNs the difference is small. The training curves of the two models are largely similar, and on plain cross-entropy the symmetry-broken model is even slightly ahead. The regularized symmetry-broken run did not finish, because of numerical instabilities, which makes its final numbers less conclusive.

This is exactly what Section 2.3 predicts. A CNN has one scaling symmetry per channel, an MLP one per neuron, so building in scale equivariance has much less to offer for a CNN. Kalogeropoulos et al. saw the same pattern: their largest gains from scale equivariance were on MLPs, and their gains on CNNs were modest.

5 Takeaways and limitations

This work is a proof of concept: it shows that a symmetry-aware metanetwork can improve the weights of networks it has never seen in a single forward pass, but only on a small scale, with small networks, small model zoos and grayscale CIFAR-10. Every metanetwork we trained also works on a single architecture, the one in its zoo. The natural next step is a metanetwork that handles varying architectures. The graph view of Section 3 makes this possible in principle, since any network can be written as a graph, but it was beyond the data and scope of this paper.
